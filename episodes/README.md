# episodes/ 目录规范（内部工单）· 原始日志 · 未剪辑视频索引 · sha256 清单

> **English abstract.** `episodes/` is the single source of every number the site shows. `runs/` holds simulation batches and `real/` real-robot batches (same CSV schema, written by `harness/run_batch.py`); `editions/<edition>/` is the publication package for one leaderboard edition: which runs it cites (`runs.csv`), the full step logs (`logs/*.jsonl`, tracked in git), the unedited-video index (`video.csv`: URL + sha256 + bytes + duration; the video files themselves live off-repo), hands-on time (`human-hours.csv`), release notes (`notes.md`, Chinese source; `notes.en.md` generated by `tools/render_en.py`) and a `SHA256SUMS` manifest covering the package and every cited run file. A published edition directory is append-only; corrections go to `errata.md`. `editions.csv` is the edition index that `tools/build_site.py` reads.

## 1 目录

```
episodes/
  README.md                 本规范
  editions.csv              期索引（一行一期；站点只认这里登记的期）
  editions/<期>/            每期发布包（发布后只追加不改；勘误另起 errata.md）
      runs.csv              model, sim_run, real_run, note —— 引用 runs/ 与 real/ 下的 run 目录（相对 episodes/）
      logs/<模型>/seed*.jsonl   发布时从所引 run 目录复制来的完整逐步日志（入仓，例外于 .gitignore 的 *.jsonl）
      video.csv             未剪辑视频索引（视频本体不入仓）
      subtitles/            tools/make_subtitles.py 产物（.srt／.zh.srt／.en.srt，入仓）
      video/                成片与原片本地工作目录（不入仓；只有 video.csv 里的 url＋sha256 随发）
      human-hours.csv       人手小时记录（裁定 2026-09-25-06）
      notes.md / notes.en.md  发布说明（中文真源／流水线英译）
      SHA256SUMS            清单：本目录全部文件＋所引 run 的 seeds/results/summary/meta/日志（路径相对仓根）
  runs/<YYYY-MM-DD>-<tag>/  仿真批次（run_batch 直接产出）：seeds.csv、results.csv、summary.csv、meta.json、logs/、frames/
  real/<YYYY-MM-DD>-<tag>/  真机批次（内部工单 产出，同 schema；另有 overhead/ 与 onboard/ 原片，不入仓）
  samples/                  相机帧样例
```

`.gitignore`：`runs/*/logs/`、`runs/*/frames/`、`*.jsonl` 不入仓；**`editions/**/*.jsonl` 例外入仓**（随发）；`editions/*/video/` 不入仓。

## 2 文件契约

### editions.csv
`edition_id,status,course,protocol_version,title_zh,title_en,trigger_model,trigger_released_at,published_at,n_sim,n_real,human_hours,baseline_run,notes_zh,notes_en`
- `edition_id`＝`<YYYY-MM-DD>-<slug>`（日期＝计划或实际发布日；按字典序即时间序）。
- `status` ∈ `planned`（候发布，站点列为 upcoming）｜`quick`（快评已发；**兜底路径**＝发布日 N=10 快评，仅当 T0 前无正式仿真数据时走）｜`formal`（正式已发；首期＝仿真 N=30 直接发，内部工单 P3）。
- `trigger_released_at`／`published_at`：ISO 8601 含时区（如 `2026-11-01T10:00:00+08:00`）；站点由二者算「发布用时」对照 48h／72h。
- `baseline_run`：同一组种子上的脚本化基线 run（astar／greedy／random），站点单列「基线与天花板」。
- `notes_zh`／`notes_en`：一句话；长文放 `notes.md`。

### editions/<期>/runs.csv
`model,sim_run,real_run,verified,note` —— `model` 必须等于该 run `summary.csv` 的 `agent`（＝`harness/models.yaml` 的键＝模型 ID＋思考档＋端点）；`verified` ∈ `rerun`（操作方已复跑）｜`self-reported`（投稿方自报，协议 §8）；`sim_run`＝`runs/…`，`real_run`＝`real/…`。缺一侧留空（站点显示待跑，不计入保真度）。

### editions/<期>/video.csv
`file,view,model,seed,platform,url,sha256,bytes,duration_s,recorded_at,note` —— `view` ∈ `overhead`｜`onboard`｜`dual`｜`summary`；`recorded_at`＝录像起始 epoch 秒（字幕对齐用，`docs/video-template.md` §3）；`sha256`／`bytes` 用 `python3 tools/manifest.py hash <文件>` 取。

### run 目录（仿真与真机同 schema）
- `summary.csv` 每模型一行：`agent,model_id,vendor,thinking,endpoint,n,n_planned,partial,sim_score_mean,sim_score_ci95,success_rate,checkpoint_score_mean,collisions_mean,collision_events_mean,total_score_mean,path_ratio_mean_success,usd_total,usd_per_success,usd_per_episode,cny_total,cny_per_success,cny_per_episode,price_tier,api_latency_mean_s,api_latency_p95_s,steps_mean,invalid_outputs_total,api_errors_total,cost_unknown,wall_s`（`agent`＝行名＝models.yaml 键＝模型 ID＋思考档＋端点）
- `results.csv` 每回合一行（五指标原料）；`seeds.csv` 种子筛选记录；`meta.json` 含 `config_sha256`、`prompt_sha256`、`seeds`、`rejection_rate`、`budget_stop`；真机 run 请在 `meta.json` 加 `"platform": "real"`（内部工单；缺省按路径 `real/` 判定）。
- 站点取数：仿真分／真机分＝`sim_score_mean`（协议 §5，[0,1]；`total_score_mean` 为旧口径对照列）；迁移差＝真机 − 仿真；每次成功成本＝`cny_per_success`／`usd_per_success` 并列；每步延迟＝`api_latency_mean_s`（P95 一并）。计分只在 `harness/scoring.py` 实现，`build_site.py` 只读列；口径改动先改 `protocol/v0.md` 再改 harness。

## 3 命令

```bash
python3 tools/manifest.py gen episodes/editions/<期>                 # 生成 SHA256SUMS（含所引 run 文件）
python3 tools/manifest.py verify episodes/editions/<期>/SHA256SUMS   # 校验；或 shasum -a 256 -c（在仓根）
python3 tools/manifest.py hash <视频文件>                             # 取 sha256 与字节数填 video.csv
python3 tools/build_site.py && python3 tools/build_site.py --check   # 站点数据重建与一致性检查
```

## 4 纪律

- **不手填数字**：站点、发布说明、视频字幕里的数字都由这里的 CSV／jsonl 生成；发现数字不对，改数据源并重建，不改渲染物。
- **随发**：一期没有完整日志或没有未剪辑视频索引就不算发布（`docs/release-day-runbook.md` §6）。
- **只增不改**：发布后的期目录只追加 `errata.md`；重跑产生新 run 目录、新的一期或 `-R1` 后缀期，不覆盖。
- **不含密钥、不含个人信息**：jsonl 里只有动作、原始模型输出、时延、成本、位姿；录像不拍到无关人员。
- 首期占位：`editions/2026-10-21-pilot01/`（status=planned；`runs.csv` 列了三模型但 run 为空，10-22 前由 v1 批填入）。
