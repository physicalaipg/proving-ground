## 6 正式 N（Q5；单期仿真总花费 ≤ $150）

- 规则：N = ⌊0.8 × 150 ÷ Σ_m c_m⌋，向下取 10 的倍数，上限 100、下限 30；c_m＝行 m 的**实测**每回合美元成本（`summary.csv` `usd_per_episode`，含重问与探活）。
- **实测（§5，`summary.csv` `usd_per_episode`）**：c_qwen = $0.0074、c_glm = $0.0077、c_deepseek = $0.0071（闲时）→ Σc = **$0.0222/回合套**（≈ ¥0.158）→ 公式值 ⌊0.8 × 150 ÷ 0.0222⌋ = 5,405 → 向下取十 5,400 → **取上限 N=100**（每期 ≈ $2.2 ≈ ¥16）。实测比 §4 估算（Σc ≈ $0.055）还低 60%：glm 行多数回合早停、三行输出均 ≈30–50 tok；DeepSeek 若改高峰时段 c ≈ $0.014，Σc 仍 < $0.03，N 不变。
