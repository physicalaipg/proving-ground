- **cute-pro/ 第二版Pro·正坐笑脸**：签名笑脸、头偏 8°；用途同上，与第二版按内容情绪选用。
- **lounge/ 第三版·贵妃躺**：侧躺撑头、眼皮半垂（v2 原图，逐字节保留）；不上平台头像；内容配图、表情包、贴纸与周边备用。

萌版只是把正装版里"真机那一次"的琥珀圆盘，变成了一只在场上的柴犬。

## 标识含义
线框透视网格＝仿真器的地面网格，也是"场"；一串由虚到实的雾青轨迹＝仿真里的多次尝试；一枚实心琥珀圆盘落在场上＝真机那一次。
一句话：仿真为主，真机为锚，落地为证。

## 角色「小M」
- 原型：日本柴犬。用了柴犬最认得出的五处：立耳（内耳粉）、白脸颊与嘴套（里白 urajiro）、两点眉、上卷的尾巴＋奶白尾尖、前爪。
- 它就是正装版里"真机那一次"的琥珀圆盘：琥珀身、暖白描边、在同一块场上；仿真尝试画成三个虚线柴犬小幽灵（雾青），由小到大飘向它，只有它是实心、有描边的。
- 项圈铭牌是雾青的小芯片，刻着 M（Fredoka SemiBold）；尾巴旁两道摆尾线。
- 表情（第二版Pro 与第三版Pro 同一张笑脸，`_shiba_head(expr="smile")`；第二版、第三版保留 v2 的圆眼）：眼睛眯成两道上弯月牙，嘴角一直咧到脸颊、张口露舌尖（舌头用腮红色），腮帮白毛鼓起，两点眉在上——柴犬的标志性笑容；头略偏（正坐 8°、贵妃躺 20°）。圆眼＋ω嘴＝`expr="alert"`，仍是第二版的成品脸。
- 第二版：坐在场上，前爪搭在场沿，眼睛盯着飘来的幽灵。第二版Pro：同一姿势，头微偏，冲你笑。第三版：侧躺在场上、头抬着、前爪伸出、后腿摊开、尾巴翘起，眼皮半垂。第三版Pro：仰面斜躺在场上，奶白肚皮朝上占身体大半，两只前爪举在下巴前，后腿一只朝天一只摊在场上，尾巴甩在场边摆两下，铭牌从项圈垂到胸前；身子缩到与头同大（chibi 头身比）。
- 贴纸式暖白描边，40 px 圆裁仍是"深底＋一张橙色狗脸"。原创角色，未参照任何既有形象。

## 字体
- 正装版：中文 Noto Serif CJK SC Black；英文 Noto Serif CJK SC SemiBold（拉丁部分即 Source Serif）；标语 Noto Serif CJK SC Regular。
- 萌版两式：中文与标语 站酷快乐体（ZCOOL KuaiLe）；英文与铭牌字母 Fredoka SemiBold。
- 均为 OFL，许可证与字体文件随 build/fonts 附上。SVG 内文字已全部转轮廓，渲染不依赖字体；改字回 build 脚本重生成。
- 正装版切无衬线：`banner_youtube2(typo="sans")` / `header_x2(typo="sans")`；铭牌字母：build.py 的 LETTER 一处改。

## 尺寸与安全区（build.py 里断言）
- avatar-800：800×800，内容在圆裁半径 380 内。
- banner-youtube-2560x1440：锁定块在 1546×423 全端安全区（x 507–2053、y 508–931）内；实测 bbox 正装 563–1997×592–848（v3.2 为 694–1866×592–848），第二版与第二版Pro 734–1826×582–858，第三版 727–1833×585–855，第三版Pro 713–1847×579–861。底部淡刻度基线满幅、可裁。
- header-x-1500x500：锁定块 bbox 正装 346–1278×144–308（v3.2 为 435–1189×144–308；左缘进了 x<380，但下缘 308 在头像区上沿 320 之上），第二版与第二版Pro 460–1164×136–316，第三版 457–1167×139–313，第三版Pro 447–1177×135–317；左下头像区（约 x<380 且 y>320）留空。X 不公布安全区，头像区为估算。

## 再生成
`bash tools/brand/regen.sh <outdir>`（内部工单 改指；脚本先装 uharfbuzz、fonttools、cairosvg、pillow，备 Noto Serif CJK 2.002，再跑 `tools/brand/build.py`；`--check` 与入库件比 sha256）。
开关都在 build.py 顶部：PRIMARY（正装横幅主字语言）、LETTER（铭牌字母）、EXPR／TILT（第二版Pro 的表情与偏头角度）。第三版Pro 的姿态参数全在 `mark_lounge()` 的默认参数里（头位与倾角、躯干位与倾角、四爪、尾巴、铭牌）；第三版＝`mark_lounge_v2()` 与 `*_lounge_v2()` 横幅，输出与 v2 包逐字节相同。

## 使用规则
五版不混用在同一张图里；标识不另加边框；深底为默认，浅底版待有场景再出（改 PAL）。横幅标语取自公开简介原句，可整行关闭（tagline=False）。
